# my-website

A simple starter website built with plain HTML, CSS, and JavaScript.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the local site:
   ```bash
   npm start
   ```
3. Open the site in your browser at:
   ```text
   http://localhost:3000
   ```

## Project structure

- `index.html` — homepage markup
- `style.css` — site styling
- `script.js` — small interactive script

## Notes

This starter is intentionally lightweight so you can customize it easily as your project grows.
